# 🪙 CampusCoin (NextGen BudgetBee)
> **Smart Spending Student Style • End-to-End Web Solutions**

CampusCoin is a full-stack student budgeting and expense tracking Web Application designed for university students to log income and expenses, view category breakdowns, set budget caps, receive automated financial insights, export high-resolution PDF reports, and provide administrator oversight.

---

## ✨ Features

- 🎨 **Fintech Grade UI/UX**: Frosted glassmorphism cards, dark/light mode toggle, dynamic font-size scaler.
- 📊 **Interactive Analytics**: Chart.js Doughnut breakdowns and 6-month income vs expense bar trends.
- ⚡ **Auto-Categorization & Smart Assistant**: Suggests categories on-the-fly as user types.
- 📑 **PDF & CSV Export**: Export monthly reports to downloadable PDF or CSV.
- 🐘 **PHP & Express REST APIs**: Dual backend support (`php-backend/api.php` and `server/server.js`).
- 🗄️ **SQL Database Schema**: Includes `campuscoin.sql` for MySQL deployment.
- 🗺️ **Interactive Sitemap**: Integrated visual platform flow diagram.

## 🚀 Quick Setup & Installation

```bash
# Clone the repository
git clone https://github.com/muhammadfaizan01-DEV/CampusCoin.git
cd CampusCoin

# Install dependencies
npm install

# Start the dev server
npm run dev
```
Open your browser at `http://localhost:3000`
